A fast, dependency-free CommonMark 0.31.2 + GFM renderer written from scratch in plain JavaScript. Its parse() returns exactly the HTML marked 18.1.3 produces with its default options, but renders it faster with offset-based sticky-regex scanning, first-character dispatch in the block and inline loops, and a single-pass inline scanner.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
